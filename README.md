Entry for the [make.fun](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138) competition "The plan make.fun will carry out in public".

`main.py` (Python 3.13, pure standard library, deterministic, no network)
writes one plan text to `entry.txt`: a plan an AI agent can carry out
itself to turn $100 into the most money in 30 days — sell a narrow,
high-need B2B micro-service to one specific niche, with a working demo on
day one.

Run it with:

```sh
python3 main.py
```

It prints the character count (Unicode code points) and the SHA-256 of
`entry.txt`.
